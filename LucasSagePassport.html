AI Lab 🔎

Don't trust, verify

Use your Sage account and approved tools. Treat each answer as a starting point, then check the source. Use made-up examples. Only put a brief, safe takeaway here; work details stay in the right Sage system.

Find and ask

Microsoft 365 Copilot

If Copilot cannot find an internal page, use Your Sage search. Open the source and check it before relying on the answer.

Find “Copilot Colleague Guidance” in Your Sage. Summarise three rules a new apprentice should know and one thing that might surprise me. Give me the source title. If you cannot find it, say so.
Find the GitHub Copilot enrolment guidance in Your Sage. Give me its title and route. Based on that guide, what should I do first, and why? If you cannot find it, say so.
First ask: “Explain JSON.” Then ask: “Explain JSON to a new apprentice in three short bullets. Use one made-up example and tell me what to verify.” What got better, and why?
A fictional partner reports an API timeout in SBX. Draft a friendly two-sentence reply with a clear next step. Do not invent a cause or promise a fix time.
Code and compare

GitHub Copilot in VS Code

Work in a new local practice file with fictional data. Read and check any code before you use it.

Write a JavaScript function that maps HTTP 200, 404 and 429 to short labels. Include a default label. Explain each line. Use no external data.

Then break one mapping on purpose in your local practice file. Ask Copilot to spot the bug. Did it catch the right one?

In GitHub Copilot Chat, open the model menu if available. Run the same safe function prompt with the default choice and one other available, approved model. Compare correctness, clarity and assumptions. Model options vary by account. If you only have one choice, tighten the prompt and compare those replies instead.
